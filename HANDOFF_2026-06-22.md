## 2. Pre-beta audit (reference — most items are operational, not code)

The application **code** is in good shape: server secrets are server-side, auth gates
`/api/chat` and `/api/delete-account`, RLS is owner-scoped, data is end-to-end
encrypted, and automated checks pass. The blockers are **operational verification** in
Supabase/Vercel, which cannot be done from the codebase.

### Critical (verify before inviting beta testers)
1. **Apply `supabase/migrations/202606190001_multi_user_hardening.sql` to the production DB**, then run `notify pgrst, 'reload schema';`.
   Without it: expense/income inserts fail (missing `month_key`), AI chat 503
   (missing `consume_ai_daily_quota`), account deletion 500 (missing
   `delete_current_user_data`), and `force` RLS + MFA(AAL2) gating are absent.
2. **Run `npm run verify:isolation`** against a staging Supabase project → expect
   `PASS: independent-account read, update, and delete isolation verified.`
3. **Confirm all Vercel Production env vars are set, with no `VITE_` prefix on secrets:**
   `SUPABASE_SERVICE_ROLE_KEY`, `TURNSTILE_SECRET_KEY`, `OPENROUTER_API_KEY`,
   `WEB3FORMS_ACCESS_KEY`, plus the rest in DEPLOYMENT_TESTING.md §13.
4. **Confirm `ledgerline-budget.vercel.app` serves the latest deployment** (the stable alias has
   stalled before).

### High
- `.gitignore` was dangerously incomplete — **FIXED this session** (see §4).
- `/api/feedback` is unauthenticated and only protected when `TURNSTILE_SECRET_KEY` is
  set (no server-side rate limit backstop). Ensure Turnstile is configured in prod.
- **Rotate the OpenRouter key** in `.env.local` — it sat in a file that was not
  gitignored. It is server-only and was never bundled to the client, but rotate as a
  precaution.

### Medium / later
- AI daily quota is consumed *before* the OpenRouter call, so rate-limited (429)
  attempts still burn a user's daily allowance. Consider counting only successful
  completions (carefully, to avoid a check/increment race).
- `.env.local` has a stale `OPENROUTER_APP_NAME=Ledgerline Budget` (old name).
- `README.md` still documents the pre-encryption plaintext schema.

### Manual testing still owed
DEPLOYMENT_TESTING.md §2–§12 require a running browser + disposable account: landing
page, header menus, signup/recovery, monthly + statement modes, recurring, AI chat,
feedback, export/import, isolation, account deletion. Use fake data only.

**Verdict:** Not ready until the 4 Critical items are confirmed; the code itself is
beta-ready.

## 4. Code changes applied this session

### 4.1 Security — `.gitignore` (audit fix)
- **File:** `.gitignore`
- **Was:** only `.vercel`.
- **Now:** ignores `node_modules`, `dist`, `.env`, `.env.local`, `.env.*.local`,
  `.vercel`, logs, `.DS_Store`.
- **Why:** prevents committing the real OpenRouter secret (and any future secrets) if
  the repo is pushed to git. Does not affect the build.

### 4.2 Visual redesign — "instrument cluster" identity
Reskin runs through the CSS variable system, so it cascades to every screen (landing,
auth, vault gate, dashboard, panels, chat, feedback, legal).

- **File:** `src/styles.css` (primary)
  - New token system: indigo-ink base `#06080F`, panels `#0D1222`, cool-white text,
    one signature accent **mint `#5BE9C0`** (ties to the name), **iris `#9B8CFF`** used
    only in the gauge, coral `#FF6F8E` for over-budget. Light theme = clean "daylight
    instrument" variant.
  - Added `--font-mono`, `--radius` (6px), `--glow`, `--line-strong`, `--grid`,
    `--on-accent` tokens.
  - **Monospace tabular numerals** on all money figures/labels (metric cards, hero
    readout, category rows, recovery code) — the core "telemetry" personality.
  - Background: faint 44px graph-paper grid + radial glow, fixed attachment.
  - Buttons de-gradient-ed → flat luminous mint with top highlight + glow + hover/active.
  - Eyebrows → mono, uppercase, wide-tracked, with a glowing mint tick (`::before`).
  - Panels → glassy `backdrop-blur`, hairline top highlight, sharper 6px radius.
  - Global radius var swap (`border-radius: 8px` → `var(--radius)`); recolored leftover
    hardcoded cyan/mint gradient tints to the new mint rgb (91,233,192) preserving alphas.
  - New signature classes: `.pace-rail`, `.pace-track`, `.pace-track-fill`,
    `.pace-track-ticks`, `.pace-readout`, `.pace-rail-scale`; HUD corner-ticks on
    `.landing-product-shot`; instrument chrome on `.early-access-pill`,
    `.landing-proof-strip`, preview chart bars.
  - `prefers-reduced-motion` + `:focus-visible` outlines added.
- **File:** `src/components/LandingPage.tsx`
  - Added the signature **pace rail** to the hero product shot (Safe-to-spend marker

  - Hero eyebrow copy → `Encrypted · Private · No bank link`; topline strong → `On pace`.
